# warframe-irc-server

An IRC server that space ninjas can connect to.

Update to OpenSSL Tls 1.3 by AI

## Building

1. Install vcpkg
  git clone https://github.com/microsoft/vcpkg
  cd vcpkg
  .\bootstrap-vcpkg.bat

2. Install OpenSSL

  .\vcpkg install openssl:x64-windows

  .\vcpkg integrate install
